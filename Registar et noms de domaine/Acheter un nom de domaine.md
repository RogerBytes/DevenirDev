# Acheter un Nom de Domaine

Ici j'explique comment vérifier l'existence d'un nom de domaine et l'acheter.

## Verifier disponibilité NDD

Il suffit d'aller utiliser le [vérificateur de l'ICANN](https://lookup.icann.org/fr/lookup), si rien n'est retourné, le NDD est disponible.

## Verifier disponibilité d'une marque

On vérifie le nom d'une marque ou d'une entreprise avec [l'outil de recherche de l'INPI](https://data.inpi.fr/recherche_avancee/marques) ou [l'outil de recherche de weeng](https://www.weeng.fr/outils/recherche-nom-marque)

Si aucun résultat pour les deux, faire une recherche approfondie via [la boutique de l’INPI](https://www.inpi.fr/services-et-prestations-domaine/recherches-personnalisees)

## Acheter un nom de domaine auprès d'un registrar

Un registrar est une entreprise autorisée à enregistrer et gérer des noms de domaine.

Je recommande l'achat de NDD via [la partie NDD de OVHCloud](https://www.ovhcloud.com/fr/domains/)

Les prix semblent compétitifs.

Pour le renouvellement au bout des 10 ans, Le plus simple est d’activer le renouvellement automatique et de mettre une carte valide, puis de la mettre à jour si elle expire (vous recevrez un rappel avant).
